## V0.1 — 看见（MVP）

**目标**：用户装上 TraceNest，选盘扫描，就能回答"AI 工具在我的电脑上留下了什么、占了多少"。

**范围（in）**：
- Rust 核心：目录扫描引擎（多线程、可中断、增量续传）、SQLite 索引（WAL）、AI 工具目录知识库 v1（F2）、信号文件检测（F1）、置信度评分（F3）。
- Tauri 2 桌面壳：首页总览、磁盘空间地图（treemap）、文件浏览器、AI 软件识别中心、项目资产页（目录级）、文件来源详情、设置页。
- 实时监控简版：notify watcher + 事件流列表（F11 的展示层）。
- 深色/浅色主题，中文 UI。

**排除（out）**：读取任何文件内容（含项目指纹哈希）、报告导出、快照差分、去重计量、MCP、历史重建。

**关键验收**：100 万文件级扫描 ≤5 分钟；归属结论 100% 携带置信度；零网络出站请求；进程断言非管理员。

## V0.2 — 理解

**目标**：从"文件地图"升级为"项目资产地图"，并开始解决处置焦虑。

**范围（in）**：
- 项目指纹与跨盘聚合（F4）——前置条件：用户确认"读取少量项目清单文件内容做哈希"的隐私授权交互方案。
- 会话 ↔ 项目关联（F5）——前置条件：确认"只读会话元数据"的实现边界。
- 共享依赖去重计量（F6）：junction/hardlink 识别，逻辑/物理占用双口径。
- 空间快照与增量对比（F7）+ 文件历史时间线（FR-6）。
- 陌生目录解释器（F8）、卸载安全清单（F9）、大文件哨兵（F14）、报告中心与导出（FR-8）。

**风险项**：F4/F5 的隐私授权 UX 需要专门设计（默认关闭、逐项开关、明确说明读了什么）。

## V0.3 — 追踪

**目标**：建立时间维度与生态接口。

**范围（in）**：
- 实时监控完整版：事件与项目/工具自动关联（F11 展示层完整化）。
- 历史重建（考古模式）：基于快照差分的 7/30 天变化时间线，含置信度标注。
- MCP Server 模式（F10）：本地只读查询接口，让其他 AI Agent 查询资产地图。
- 隐私审计模式（F13）：行为账本、网络请求审计面板。

**明确排除**：进程级实时归因（需管理员权限）、全盘 USN 历史回放（需管理员权限）——技术边界见 [TECH_FEASIBILITY.md](../research/TECH_FEASIBILITY.md)。

## V1.0 — 发布

- 跨平台验证：macOS（FSEvents + TCC 权限适配）、Linux（inotify 限制适配）。
- 安装器与签名（Windows MSI/NSIS；签名证书待定，涉及预算需用户决策）。
- 规则库社区化：适配器规范文档 + PR 流程。
- 文档站、Demo 数据集（脱敏合成数据）、公开仓库治理（LICENSE、CONTRIBUTING、安全披露策略）。

## 里程碑风险一览

| 风险 | 影响版本 | 缓解 |
|---|---|---|
| 无管理员权限导致"历史发现"能力低于用户预期 | V0.1 宣传口径 | PRD 中明确能力边界；用"目录知识库+信号文件"弥补 |
| treemap 大数据渲染性能 | V0.1 | 可见节点上限 + 下钻；不行则 canvas 兜底 |
| AI 工具目录规则时效性 | 全部 | 规则包版本化 + 本地导入 + 社区 PR |
| F4/F5 隐私边界引发用户不信任 | V0.2 | 默认关闭 + 行为账本 + 开源可审计 |
| 单人开发节奏 | 全部 | V0.1 严控范围（只做"看见"） |
