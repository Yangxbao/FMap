## 1. 产品定位

**TraceNest — AI File Asset Tracker**

一个跨平台、隐私优先的 **AI 文件资产地图与追踪工具**。

- **产品口号**：让 AI 在电脑上留下的每一个文件，都有迹可循。
- **一句话定位**：AI 时代的磁盘地图 + 文件侦探 + 卸载安全员。
- **形态**：本地桌面应用（Windows 优先），完全开源，无注册、无 API Key、无遥测。
- **默认运行方式**：普通用户权限，完全本地，只读。

### 1.1 背景与问题

用户同时使用多个 AI 编码/助手工具（Codex、WorkBuddy、ZCode、豆包、Claude Code、Cursor、DSH 等），这些工具在 C、D、E 等多个磁盘上持续产生项目文件、下载、缓存、模型、依赖和临时文件。由此产生 8 类高频困惑：

| # | 用户困惑 | TraceNest 的答案 |
|---|---|---|
| 1 | 不知道 AI 把项目生成到了哪里 | 项目资产页 + 扫描定位 |
| 2 | 不知道 AI 下载了哪些东西 | 下载目录知识库 + 大文件哨兵 |
| 3 | 不知道哪个 AI 软件占了多少空间 | AI 工具占用排行 |
| 4 | 不知道某个文件属于哪个项目 | 归属推断 + 项目指纹（V0.2） |
| 5 | 不知道过去生成的文件在哪里 | 会话映射 + 历史时间线（V0.2/0.3） |
| 6 | 不知道 AI 工具产生了哪些缓存和日志 | 目录知识库解释器 |
| 7 | 卸载时害怕误删重要文件 | 卸载安全清单（含风险分级） |
| 8 | 多工具混用，文件来源混乱 | 统一来源置信度视图 |

### 1.2 目标用户

- **主要画像**：同时使用 2+ AI 编码工具的开发者 / 重度 AI 用户，Windows，机器上有 C/D/E 多盘。
- **次要画像**：帮家人朋友"清理电脑"的技术型用户；关心隐私不想装"全家桶清理软件"的用户。
- **反画像（不服务）**：需要自动清理、自动优化的用户（产品只读，不做处置）。

### 1.3 非目标（Non-Goals）

明确不做：文件删除/移动/重命名、修改注册表或环境变量、云同步、注册账号、文件内容全文索引、自动清理、以管理员权限运行的功能（ETW 进程归因、MFT 全盘枚举等）。

## 2. 产品原则（约束即需求）

以下约束来自用户决策，全部为**硬性需求**，任何设计不得违反：

1. Windows 优先，架构上兼容 macOS/Linux；
2. 追踪过去已存在的文件 + 追踪未来新产生的文件；
3. 对用户文件**只读**；
4. 完全开源（GitHub 发布）；
5. 本地运行，不注册、不需要 API Key；
6. 不上传用户文件和路径（一切分析在本地）；
7. 不以管理员权限启动；
8. 不要求关闭 Windows Defender，不加排除项；
9. 不修改系统环境变量、注册表、用户文件；
10. 不提供文件删除、移动、重命名功能。

## 3. 功能需求

优先级定义：P0 = V0.1 必须有；P1 = V0.2；P2 = V0.3+。功能编号沿用 [INNOVATION_IDEAS.md](../research/INNOVATION_IDEAS.md)。

### 3.1 FR-1 首页总览（P0）

- 展示：受管磁盘列表与容量、已识别 AI 工具数、已识别项目数、AI 相关文件总占用、最近一次扫描时间。
- 最近项目卡片（Top 5）、最近文件事件流（Top 10）。
- 全局搜索框：按文件名/目录名模糊搜索（FTS5）。
- 首次运行引导：选择扫描的磁盘/目录 → 后台扫描 → 展示进度。

### 3.2 FR-2 磁盘空间地图（P0）

- Treemap 可视化（手写 squarified treemap 或 D3）+ 目录树切换视图。
- 按"AI 归属"着色（每个 AI 工具一个色系；非 AI 归属为中性色）。
- 大数据策略：前端渲染节点数上限（建议 ≤20,000 可见节点），下钻代替全量渲染。
- 点击节点 → 文件详情抽屉（FR-9）。

### 3.3 FR-3 文件浏览器（P0）

- 面包屑 + 可排序列表（名称/大小/mtime/归属/AI 信号）。
- 支持按磁盘、目录类型（缓存/会话/下载/项目）过滤。
- 显示"为什么判定为 X 工具"的依据链入口。

### 3.4 FR-4 AI 软件识别中心（P0）

- 每个 AI 工具一张卡：检测状态（未发现/已发现/仅规则）、发现路径数、占用、置信度分布。
- 未识别但有候选信号的目录进入"待确认"区（用户可一键确认/忽略，反馈本地存档）。
- 规则库版本展示 + 本地导入规则包入口（不联网）。

### 3.5 FR-5 AI 项目资产页（P0）

- 项目列表：名称（从信号文件/目录名推断）、路径、大小、涉及工具、最近活跃时间。
- V0.1 以"目录级"为项目单元；V0.2 引入项目指纹后升级为"逻辑项目"（跨盘聚合）。

### 3.6 FR-6 文件历史时间线（P1）

- 以快照差分（F7）与事件流（F11）合成的时间线：某目录近 7/30 天的变化。
- 明确标注数据来源与置信度（快照差分=准确，时间戳推断=inferred）。

### 3.7 FR-7 实时监控页（P0 简版 / P2 完整版）

- V0.1：watcher 开关、受监视目录列表、事件实时流（工具内置）。
- V0.3：事件与项目/工具自动关联、历史重建。

### 3.8 FR-8 报告中心（P1）

- 报告类型：工具占用报告、卸载安全清单（F9）、空间变化报告（F7）、大文件哨兵（F14）。
- 导出格式：Markdown / JSON / CSV（本地保存，用户选择路径）。

### 3.9 FR-9 文件来源详情（P0）

- 任意文件/目录的详情视图：路径、大小、时间戳、所属卷、归属工具、置信度、依据链（命中了哪些信号/规则）、父目录上下文。
- 数据全部来自本地 DB；不发起任何网络请求。

### 3.10 FR-10 设置页（P0）

- 扫描范围（磁盘/目录勾选）、排除模式（默认排除系统目录）、规则库管理、监控开关与监视列表、隐私面板（行为账本、清除数据库）、主题（深色/浅色/跟随系统）、语言（中文优先，架构支持 i18n）。

### 3.11 非功能需求

| 维度 | 指标（V0.1 验收口径） |
|---|---|
| 性能-扫描 | 100 万文件级别目录树 ≤ 5 分钟（M.2 SSD，排除网络盘），UI 不卡顿（扫描在 Rust 后台线程） |
| 性能-查询 | 任何页面交互响应 ≤ 200ms（DB 查询走索引） |
| 性能-内存 | 稳态运行 RSS ≤ 500MB（treemap 只渲染可见子树） |
| 隐私 | 零网络出站请求（除"打开官网链接"由用户点击触发）；DB 不含文件内容 |
| 安全 | 不请求管理员；进程令牌校验（启动时断言非提权） |
| 可靠性 | 扫描可中断可续传；崩溃后 DB 一致（WAL） |
| 兼容 | Windows 10 21H2+ / Windows 11；无 WebView2 时给出引导安装提示 |
