# TraceNest 安全与隐私设计（SECURITY）

> 版本：v0.9（夜间研究稿） · 日期：2026-11-03
> 性质：本文档是产品**承诺的可执行规范**——每一项都要能被开源社区验证。

---

## 1. 威胁模型

TraceNest 自身是"高敏感数据的只读观察者"：

| 资产 | 风险来源 | 缓解方向 |
|---|---|---|
| 用户文件路径/目录结构（DB） | DB 泄露 = 用户磁盘地图泄露 | 本地存储 + 可清除 + 无网络 |
| 用户对 TraceNest 的信任 | 越权行为（写文件、联网、提权） | 最小能力面 + 行为账本 + 开源审计 |
| 规则包供应链 | 恶意社区规则（路径注入等） | 规则 schema 校验 + 本地导入人工确认 |
| Tauri/前端 | WebView 攻击面 | CSP 严格化 + 关闭多余权限 |

**明确假设**：本机已被攻陷的场景不在防御范围内（TraceNest 无法防御已提权的本机攻击者）。

---

## 2. 硬性安全承诺（需求级）

每一条都来自产品原则，写进 V0.1 验收（见 ACCEPTANCE_CRITERIA）：

1. **只读**：代码库中禁止引入任何删除/移动/重命名用户文件的 API 调用（`std::fs::remove_*`、`rename` 等在 CI 中用 grep 门禁拦截；`cargo deny` 辅助）。
2. **不提权**：启动时自检进程令牌（Windows 检查 token elevation），发现提权立即拒绝启动并提示。
3. **零网络**：应用不包含任何遥测/上报/更新检查代码。唯一的网络动作 = 用户点击"打开官方文档链接"（系统浏览器打开，应用本身无网络权限）。
4. **不改系统**：不写注册表（除 Tauri 安装器标准卸载项）、不改环境变量、不写 Defender 排除项。
5. **不加 Defender 排除项 / 不劝用户关闭杀软**：文档与 UI 均不得出现此类建议。

## 3. 数据安全

### 3.1 数据库

- 内容：仅元数据（路径、大小、时间、归属结论）。**不存储文件内容**。
- 位置：`%APPDATA%/TraceNest/`（用户私有目录）；设置中可迁移位置。
- 泄露缓解：一键"清除全部数据"；一键"导出 DB 供自查"（透明性）；DB 文件 ACL 校验为仅当前用户。
- 可选增强（V1.0 评估）：SQLCipher 加密 DB——**默认不启用**（增加崩溃恢复/兼容复杂度，收益取决于用户画像，作为社区讨论项）。
- 日志：应用日志只记录模块级事件（"扫描完成，N 条"），**不打印完整用户路径**（默认脱敏为盘符+目录数；调试模式由用户显式开启）。

### 3.2 规则包（供应链）

- 规则包 JSON 必须通过 schema 校验（`serde` 强类型 + 未知字段拒绝）。
- 路径模式仅允许白名单变量展开（`%APPDATA%` 等已知环境变量），禁止任意代码/脚本。
- 社区包导入需用户在 UI 中人工确认并展示包内容摘要；包内 `doc_url` 仅作为展示文本，不自动访问。

### 3.3 隐私行为账本（F13，V0.3）

- 应用内可见账本：扫描了哪些根、DB 行数、事件数、网络请求计数（恒为 0 的展示本身就是承诺的一部分）。

## 4. 应用安全（Tauri 2 配置规范）

- **CSP**：`default-src 'self'`；禁 inline script；`img-src 'self' data:`；不引用任何第三方 CDN（原型中的在线字体/CDN 在正式版全部本地化）。
- **能力最小化**：Tauri 2 capability 文件只开放自定义 command；禁用 `shell-open-anything`（仅允许 `https:` 链接 open）；禁用文件系统插件的全量访问（前端永远不直接 touch 用户文件系统，一切经 Rust 层）。
- **更新机制**：V0.x 不做自动更新（避免供应链与网络面）；GitHub Releases 手动下载，后续如引入需签名校验并单独立项。
- **依赖治理**：`cargo audit` + `npm audit` 进 CI；锁文件入库。
- **安装器**：MSI/NSIS per-user 安装（不需要管理员）；不写 HKLM；签名（V1.0 决策项，涉及证书预算，交用户决定）。

---

## 5. 与操作系统的权限边界

无管理员权限决定了能力上界（详见 TECH_FEASIBILITY）：

- ✅ 可做：目录元数据遍历、用户目录 watch、每文件 USN 记录、本用户进程列表。
- ❌ 不可做且**明确不做**：全盘 MFT/USN 枚举、ETW 文件事件归因、其他用户数据访问、系统目录 watch。
- 任何"看起来像能做到"的替代方案都必须先过"无提权 + 零联网 + 只读"三关。
