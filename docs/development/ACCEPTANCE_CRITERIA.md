# TraceNest 验收标准（ACCEPTANCE_CRITERIA）

> 版本：v0.9（夜间研究稿） · 日期：2026-11-03
> 口径：每条标准必须**可观察、可复现**；标注 [自动] 的进 CI，[手动] 的为发布前人工检查单。

## V0.1 验收清单

### A. 安全与隐私（一票否决项）

- [ ] A1 [自动] CI grep 门禁：Rust 代码中无 `fs::remove_file|remove_dir_all|rename` 面向用户路径的调用（允许清单：DB 目录内部操作需显式标注豁免注释）
- [ ] A2 [手动] 以管理员身份启动应用 → 应用拒绝启动并给出明确提示
- [ ] A3 [自动] 网络面审计：构建产物中无 HTTP 客户端调用路径（除系统浏览器打开链接）；运行时抓包 10 分钟零出站请求
- [ ] A4 [手动] 卸载应用后：不残留注册表项（除安装器标准卸载信息）、不残留环境变量修改
- [ ] A5 [手动] 日志抽查：默认日志无完整用户路径输出
- [ ] A6 [手动] DB 中无文件内容字段（schema 审查）

### B. 扫描与数据

- [ ] B1 [自动] 合成文件树（100 万文件、平均深度 8）全量扫描 ≤ 5 分钟（基准机：M.2 SSD，排除网络盘），扫描期间 UI 可交互
- [ ] B2 [自动] 扫描中断后可续传，续传结果与一次扫完一致（行数+size 聚合相等）
- [ ] B3 [自动] junction/符号链接不跟随（构造循环链接不挂起、不重复计数）
- [ ] B4 [自动] 无权访问目录被跳过并计数，UI 显示"N 项无权读取"
- [ ] B5 [手动] C/D/E 三盘实际扫描（用户机器）结果合理：总量与已知磁盘占用误差 ≤ 5%（排除权限跳过项）

### C. 归属与识别

- [ ] C1 [自动] 规则集测试：内置规则包 v1 全量单测（每个工具 ≥3 正例 + ≥2 反例）
- [ ] C2 [手动] 对本机已装 AI 工具目录（Claude Code / Codex / Cursor 等）识别正确，结论 100% 携带置信度标签
- [ ] C3 [自动] 无匹配时输出 unattributed（不允许空 tool_id 的"伪归属"）
- [ ] C4 [手动] 依据链可展开：每条归属能看到命中的规则/信号

### D. 查询与界面

- [ ] D1 [自动] 100 万行 DB 上：query_tree / query_files / FTS 搜索 P95 ≤ 200ms（基准测试入库）
- [ ] D2 [手动] treemap 10 万节点子树下钻流畅（无 >300ms 卡顿），超过可见上限自动降级
- [ ] D3 [手动] 10 个页面与 prototype/ 一致（布局/主题/中文文案）；深浅主题切换正确
- [ ] D4 [自动] 表格虚拟滚动在 10 万行数据下内存稳定（RSS ≤ 500MB）

### E. 实时监控

- [ ] E1 [自动] 在受监视目录创建/修改/删除文件 → 事件 ≤ 2s 出现在事件流
- [ ] E2 [自动] 事件风暴（脚本 1s 内创建 5,000 文件）→ 去抖生效、无 UI 冻结、overflow 有计数上报
- [ ] E3 [手动] watcher 关闭后无残留句柄（Process Explorer 抽查）

### F. 工程质量

- [ ] F1 [自动] cargo test / clippy / audit、tsc、npm audit 全绿
- [ ] F2 [手动] 安装包（NSIS/MSI）在干净 Win11 虚拟机安装-运行-卸载成功（无需管理员）
- [ ] F3 [自动] README/SECURITY 承诺与行为一致性检查单执行

## V0.2 / V0.3 验收标准（先立框架，开工前细化）

- V0.2：项目指纹聚合正确率（同一逻辑项目跨盘合并 ≥90% 于测试集）；逻辑/物理占用双口径数字一致；卸载清单风险分级标注完整；报告导出文件可被再次导入校验。
- V0.3：事件关联归属的准确率报告（标注 inferred）；历史时间线置信度标注 100% 覆盖；MCP server 通过协议合规测试（列出/调用工具）；隐私账本与实际行为一致（网络请求计数恒 0）。

本阶段交付物 = 文档 + 静态原型，验收口径：

- [x] 技术可行性 10 问均有来源或明确"待验证"
- [x] ≥10 项创新功能且含"明确不做"清单
- [x] 13 份指定文档 + 环境报告 + 交接文档齐全
- [x] 原型 10 个页面可打开、标注 DEMO、双主题
- [x] 全程未执行任何破坏性操作（仅创建新目录与文件）
